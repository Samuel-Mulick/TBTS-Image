# TBTS-Image

Author: Samuel Mulick

Date: 9-8-2026

TBTS Image is a simple program to allow a user to quickly apply tags to, order, or resize images. It allows batch application, so the user can conform images to a standard quickly. The output is an image named with a logical structure that can be broken down by other programs to retrieve information or perform an action.

The original intent is to be used in conjuction with a custom OBS Studio plugin that parses the file name and displays certain elements of the name on the screen.
